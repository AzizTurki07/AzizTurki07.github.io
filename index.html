Houwiya

Identity verification (eKYC) platform for Tunisian passports and ID cards.

  • Designed and built the whole platform alone: Spring Boot API, Python FastAPI AI service, Angular web app and Android app.
  • Automatic reading of passports (MRZ with check digits) and Arabic Tunisian ID cards, then selfie face matching and a head-turn liveness check.
